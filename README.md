# cgui

ローカルで動く、ファイルを「見る・書き換える」ためのGUI。Claude Code と git の操作は CLI に任せ、GUI と CLI はプロジェクトのファイルだけでつながる。設計は [DESIGN.md](./DESIGN.md)、画面の検討用プロトタイプは [prototype.html](./prototype.html)。

CLI がローカルサーバーを立て、表示された URL（`http://127.0.0.1:27182/?t=...`）をブラウザで開いて使う。ブラウザは自動では開かない。

## 今できること

- `cgui .` でフォルダをプロジェクトとして開く（背景のサーバー。2回目は、動いているサーバーにタブを足す）
- ファイル一覧（フォルダの移動、選択位置の記憶）、ブックマーク、Git の差分（読み取り専用）
- プレビューと編集: MD（チェックボックス、`[[リンク]]`、画像、Mermaid）、`.mmd`、HTML（図解）、コード（色付け）、画像
  - 編集して `Ctrl+S` で保存する。未保存のタブには「●」が付く
  - MD のチェックボックスは、クリックで更新される
  - 表示に対応していないファイル（テキストではないもの）は、プレビューで知らせる
- プレビューのタブ、プロジェクトのタブ、ブックマークしたプロジェクト（閉じても、開き直すと元の状態に戻る）
- CLI がファイルを書き換えたら、監視して画面に反映する。編集中のファイルが外で変わったときは、上書きせず、選んでもらう
- 一覧の「…」メニューから、名前の変更、パスのコピー、削除、ブックマーク
- パネルの表示切替と、一覧の幅の調節（設定は保存される）

設計は [DESIGN.md](./DESIGN.md) を参照。

## 導入

WSL2（Ubuntu など）で使う前提で書いている。macOS や Linux でも同じ手順で入る。

### 1. 必要なもの

- WSL2。プロジェクトは WSL 側（`/home/...`）に置く。`/mnt/c/...` に置くと、ファイルの変更を検知できない
- Node 20 以上（WSL の中に入れる。Windows 側に入れたものは使えない）
- `git`（Ubuntu の WSL なら最初から入っていることが多い。なければ `sudo apt install git`）
- Windows 側のブラウザ（Chrome でも Edge でも、何でもよい）

Node が入っていなければ、nvm で入れる。

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# ターミナルを開き直してから
nvm install --lts
node -v   # v20 以上なら OK
```

### 2. cgui を入れる

```bash
# 公開後
npm i -g github:kokuto821/gui-editor

# 非公開のうち（GitHub に SSH 鍵を登録し、リポジトリを読めること）
npm i -g git+ssh://git@github.com/kokuto821/gui-editor.git
```

入れるときに画面のビルドが走るので、少し時間がかかる。版を決めて入れるときは、末尾に `#v0.1.0` のようにタグを付ける。

```bash
cgui --help   # 説明が出れば、入っている
```

### 3. 更新と削除

```bash
npm i -g github:kokuto821/gui-editor   # 更新（同じコマンドをもう一度）
cgui stop                              # 動いているサーバーを止める（更新の後は、止めてから開き直す）
npm rm -g cgui                         # 削除
```

### うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| 「ポート 27182 は、ほかのプログラムが使っています」と出る | `cgui --port 4777 .` のように、別の番号を指定する（動いているサーバーがあれば、そのポートがそのまま使われる） |
| ブラウザが勝手に開かない | 仕様。表示された URL を Windows のブラウザに貼る。開きたいときは `--open`（`CGUI_BROWSER` で、使うブラウザの実行ファイルを指定できる） |
| 画面が開くが「接続が切れています」と出る | `cgui stop` のあと、もう一度 `cgui .` を実行する。ログは `~/.cache/cgui/server.log` |
| 変更が画面に反映されない | プロジェクトが `/mnt/c/...` にないか確認する。WSL 側（`/home/...`）に置く |
| `npm i -g` で権限のエラーが出る | `sudo` は使わず、nvm で入れた Node を使う（上の手順） |

## 使い方

### 起動と終了

```bash
cgui .              # 今のフォルダをプロジェクトとして開き、URL を表示する
cgui ~/work/blog    # フォルダを指定して開く
cgui stop           # サーバーを止める
cgui --open .       # URL を表示したうえで、ブラウザも開く
cgui --port 4777 .  # ポートを指定する（環境変数 CGUI_PORT でも指定できる）
```

- 表示された URL を、ブラウザで開く。ポートは **27182** に固定してあるので、毎回同じ `http://127.0.0.1:27182/` になる。URL の `?t=` 以降はトークン（サーバーを起動するたびに変わる）で、これが付いていないと開けない。
- 別のフォルダでもう一度 `cgui` を実行すると、動いているサーバーにタブが増える。開いている画面には、すぐ反映される。
- ターミナルは、すぐに使える状態に戻る（サーバーは背景で動き続ける）。
- プロジェクトのタブを閉じても、サーバーは止まらない。止めるときは `cgui stop`。

### 画面

```
┌─[＋][👁][💾][⌂]│[パネル]─────────────────────────┐  ツールバー
├─[proj]─[blog]─[＋]─────────────────────────────┤  プロジェクトのタブ
├─[🔖][📄][Git]──────┬─[PLAN.md ×][arch.md ●][＋]─┤
│ ▸ docs/            │  プレビュー（閲覧 / 編集）   │  左: 一覧　右: プレビューとそのタブ
│ PLAN.md          … │                           │
├────────────────────┴───────────────────────────┤
│ proj / docs / arch.md                           │  ステータスバー
└─────────────────────────────────────────────────┘
```

- **ツールバー**: `＋`（プロジェクトのメニュー）、閲覧 / 編集の切替、保存、プロジェクトのフォルダへ戻る、表示するパネル。
- **一覧の切替**: ブックマーク / ファイル / Git の差分（Git のボタンのバッジは、未コミットの件数）。
- **プレビューのタブ**: アクティブなタブは、一覧で選んでいるものに従う。一覧でダブルクリックすると、新しいタブで開く。`＋` で今のタブを複製する。
- **一覧の「…」**: ファイルは「ブックマーク」「名前を変更」「パスをコピー」「削除」。フォルダは「プロジェクトとしてブックマーク」「プロジェクトとして開く」も出る。
- **Git の差分**: 左に Changes（作業ツリーの変更）と Commits（履歴）、右に差分。読み取り専用。
- **幅の調節**: 一覧とプレビューの境界をドラッグする（最小 0、ダブルクリックで元に戻す）。
- **ファイル**: 表示に対応していないものも一覧に出る。MD の相対リンク、`[[docs/a.md]]` は、そのファイルへ移る。
- 保存していない編集は、ファイルごとに残る。別のファイルに移っても消えない。

### キー操作

| 操作 | キー |
| --- | --- |
| 上下に移動 | `↑` `↓` / `j` `k` |
| 親のフォルダへ | `←` / `h`（ホームより上には行けない。ホームの外のプロジェクトは、そのフォルダまで） |
| フォルダの中へ | `→` / `l`（ファイルの上では何もしない） |
| 編集に入る | `Enter` / `e`（テキストのファイルのみ） |
| 編集をやめる | `Esc` |
| 保存 | `Ctrl+S`（Mac は `⌘S`。入力中も受ける） |
| 先頭 / 末尾へ | `g` / `G`（`Home` / `End`） |
| プレビューをスクロール | `d` `u`（半ページ） |
| ファイルと差分の切替 | `v` |
| 差分画面で、Changes / Commits の切替 | `←` `→`（`↑` `↓` で選ぶ） |
| 新しいプロジェクト（`~` を開く） | `Alt+T` |
| プロジェクトを閉じる | `Alt+W` |
| プロジェクトを切り替える | `Alt+1` 〜 `Alt+9` |

- 一覧のファイルは、マウスで選んでもよい。フォルダはダブルクリックで中へ入る。
- プレビューをクリックすると、キー操作の対象がプレビューに移る。`↑` `↓` / `j` `k` で少しずつ、`d` `u` で半ページ、`g` `G` で先頭 / 末尾へ動く。`Esc` で一覧に戻る。
- テキスト入力中（編集、名前の変更）は、上のキーを奪わない（`Esc` と `Ctrl+S` だけ受ける）。
- ブラウザの `Ctrl+T` などは奪えないため、プロジェクトの操作は `Alt` 系にしている。

### 設定とファイルの場所

| もの | 場所 |
| --- | --- |
| サーバーの情報（ポートとトークン） | `~/.cache/cgui/lock.json` |
| サーバーのログ | `~/.cache/cgui/server.log` |
| 設定（ブックマーク、パネル、幅） | `~/.config/cgui/settings.json`（`$XDG_CONFIG_HOME` があればその下） |
| ポート | 既定 `27182`。`--port` か、環境変数 `CGUI_PORT` |
| ブラウザの指定（`--open` のとき） | 環境変数 `CGUI_BROWSER` |

- サーバーは `127.0.0.1` だけで待ち受ける。URL のトークンと `Host` / `Origin` を確かめるので、ほかのマシンや、開いている別のサイトからは使えない。
- 読めるのは、ホームと、開いているプロジェクトのフォルダの下だけ。

## 開発

```bash
npm install
npm run build      # 画面（dist/web）とサーバー（dist/cli.js）を作る
npm link           # cgui コマンドを、このフォルダへのリンクにする
npm test           # vitest
npm run typecheck
npm run dev:web    # 画面だけを Vite で動かす（サーバーは別に要る）
```

構成は DESIGN.md の6章「内部構成」を参照。
